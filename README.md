# MecaAutoCil

Sitio web académico para un taller automotriz. Presenta una página principal y páginas dedicadas a mantenimiento, diagnóstico y reparación.

## Páginas

- [Inicio](index.html)
- [Mantenimiento](mantenimiento.html)
- [Diagnóstico](diagnostico.html)
- [Reparación](reparacion.html)

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Ejecutar localmente

Clona el repositorio y abre `index.html` en un navegador moderno. Conserva las carpetas `CSS/`, `JS/` y `assets/` para mantener las referencias a estilos, scripts e imágenes.

## Nota de portafolio

Este proyecto es una demostración frontend. No se conecta a un sistema real de reservas ni a una base de datos. El README describe las páginas presentes en el repositorio; no implica que el sitio tenga un despliegue público.
